Приоритетные дополнения и воспроизводимые проверки
- Чистый эксперимент по prompt‑инъекции на новом экземпляре (без старых отзывов): (1) без вредного отзыва получить /assistant/context и решение модели; (2) добавить вредный отзыв, повторить; сравнить JSON решений. Оценить только итоговый JSON модели и реакцию сервера на одинаковые вредные решения.
- Ненарушающий DoS тест delete_tree по HTTP: как гость POST /assistant/execute с tool=delete_tree, path="files/bob"; затем GET /files?user=bob должен давать ошибку; /health остаётся 200. Подтверждает D-01 без удаления корня.
- Подтвердить разграничение файлов между клиентами: с токеном Alice GET /files?user=bob и с traversal в path — должно быть запрещено после фиксов; до фиксов наблюдается 200 (сейчас показано для гостя).
- Уточнить утечку в логах: (1) выполнить /login (пароль в теле), (2) любой запрос с X-Token, (3) GET /debug/logs как гость — убедиться, что видны и пароль, и токен; затем использовать извлечённый токен для POST /orders (цепочка I-01→S-02).
- Проверка GET /orders с клиентской сессией (Alice): подтвердить, что до исправлений видны заказы с разными owner (усиление I-03).
