# Инструкции для агента

Все пути ниже указаны относительно каталога `practices/practice_04`,
в котором находится этот файл. Отвечай на русском языке.

## Структура проекта

RoomBook использует Python, FastAPI и SQLite. Код проекта находится
в `room_booking_project`.

| Путь | Назначение |
|---|---|
| `room_booking_project/app/api.py` | Создание приложения и HTTP endpoints |
| `room_booking_project/app/models.py` | Модели данных и входная валидация |
| `room_booking_project/app/storage.py` | Работа с SQLite |
| `room_booking_project/tests/` | Тесты публичного API |
| `room_booking_project/scripts/check.sh` | Запуск проверки проекта |
| `room_booking_project/requirements.txt` | Зависимости Python |
| `room_booking_project/docs/style-guide.md` | Принятый style guide проекта |

## Контекст и требования

Перед изменениями прочитай:

- `room_booking_project/README.md` — описание проекта, контракт и ограничения.
- `room_booking_project/PLAN.md` — требования фич A и B, последовательность этапов.
- `room_booking_project/tests/test_app.py` — пример тестов публичного API.
- `room_booking_project/scripts/check.sh` — действующая процедура проверки.

## Проверка

Из каталога `practices/practice_04`:

```sh
sh room_booking_project/scripts/check.sh
```

Из каталога `room_booking_project`:

```sh
sh scripts/check.sh
```

Для прямых команд Python используй окружение проекта `.venv`.
Тесты должны использовать временную SQLite-базу, как в существующих fixtures.

## Ограничения

- Объём изменений ограничен текущим поручением.
- Меняй код и тесты в `room_booking_project`. Файлы среды практики меняй
  только в рамках поручения по её настройке.
- Сохраняй базовый API, формат данных и действующую валидацию.
- Не меняй контракт в README/PLAN, зависимости, скрипт проверки или настройки
  агента без соответствующего поручения. Не ослабляй тесты ради успешной проверки.
- Не меняй базу с пользовательскими бронированиями и материалы других практик.
- Для отдельных worktree используй отдельные базы и порты.
- Не выполняй commit, merge или push без явного поручения после приёмки результата.
