## Ответ со ссылками на источники

Подтверждённые роли и границы:

- Роли: человек‑ревьюер подтверждён как пользователь результата в [context.md — «Сущности учебного кейса» раздела «Context Pack для первого рабочего сценария»](../../practice_01/context.md); разработчик, отправляющий diff, подтверждён исходным сценарием в [product_management.md — «Первый рабочий сценарий»](../../practice_01/product_management.md).
- Правила (подтверждённые требования): [context.md — «Правила проверки diff»](../../practice_01/context.md): SEC-1, API-1, REL-1, OUT-1, SCOPE-1, QA-1, OBS-1.
- Неизвестные сведения: [context.md — «Что пока неизвестно»](../../practice_01/context.md): точный HTTP-статус и тело при тайм-ауте внешнего LLM не определены.
- Проблемы и критерии исправления артефакта: [prompts.md — «Журнал экспериментов Практики 2», строка техники RAG](../prompts.md).

Как исправить сценарий, не превращая предложения в требования:

- Разделить акторов на «Разработчик (отправляет diff)» — по [product_management.md — «Первый рабочий сценарий»](../../practice_01/product_management.md), и «Человек‑ревьюер (использует результат)» — по [context.md — «Сущности учебного кейса»](../../practice_01/context.md).
- Предусловия не должны требовать «отсутствия секретов»; наличие секретов допустимо, а очистка — обязанность сервиса по SEC-1 — по [context.md — «Правила проверки diff» → SEC-1](../../practice_01/context.md) и критериям из [prompts.md — строка техники RAG](../prompts.md).
- Проверить границы размера: принять ровно 20000 и вернуть 413 при 20001 — по [context.md — «Правила проверки diff» → API-1](../../practice_01/context.md) и критериям из [prompts.md — строка техники RAG](../prompts.md).
- Представить OUT-1 как подтверждённое требование — по [context.md — «Правила проверки diff» → OUT-1](../../practice_01/context.md).
- Для REL-1 вернуть контролируемый ответ, но статус/тело пометить как «неизвестно/предложение» — по [context.md — «Правила проверки diff» → REL-1](../../practice_01/context.md) и [context.md — «Что пока неизвестно»](../../practice_01/context.md).
