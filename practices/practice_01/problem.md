# Проблема и метрики

## Проблема

- Пользователь: человек-ревьюер, использующий рекомендации AI Reviewer.
- Ситуация: требуется быстро получить первичный разбор diff PR с указанием рисков и проверок.
- Что происходит сейчас: текущая реализация пересылает сырой diff во внешний LLM и возвращает неструктурированный ответ {"comment": ...}; отсутствуют гарантии очистки секретов, ограничения размера и контролируемых ошибок.
- Почему это мешает пользователю или бизнесу: риск утечки секретов (SEC-1), нестабильность и задержки при больших диффах (API-1), непредсказуемые ошибки без тайм-аута (REL-1), неудобство потребления результатов из-за неподходящего формата (OUT-1).
- Что не входит в задачу: аутентификация, интеграция с реальным GitHub, подтверждение эксплуатации в продакшене.

## Метрики

Выберите измеримые показатели, относящиеся к проблеме. Не используйте VTG, IRR, WACC, CSAT или другую метрику только ради названия.

| Метрика | Текущее значение или способ замера | Целевое изменение | Когда измеряем | Источник данных |
|---|---:|---:|---|---|
| Доля ответов в целевом формате (OUT-1) | Неизвестно; измерить по ответам API | ≥ 95% запросов возвращают summary, risks≤3, checks | На каждом релизе и ежедневно | Логи API; выборочная проверка |
| Отклонение >20k символов (API-1) | Неизвестно; провести тесты с 20k+ | 100% запросов >20k отклоняются 413 | Перед релизом и при регрессии | Интеграционные тесты |
| Обработка тайм-аута LLM 10с (REL-1) | Неизвестно; измерить на стенде | 100% превышений 10с завершаются контролируемым ответом | Непрерывно | Технические логи и тесты |
| Утечки секретов в prompt (SEC-1) | Неизвестно; перехватить prompt в тестовой среде | 0 обнаруженных секретов | Перед релизом | Логи тестового прокси LLM |

## Почему изменение метрики подтвердит решение проблемы

Соответствие OUT-1 делает результат пригодным для работы. API-1 и REL-1 контролируют ресурсы и стабильность. Нулевые утечки по SEC-1 снижают риск нарушения безопасности.

## Как использовали AI

- Для чего: сформулировать учебную проблему и измеримые метрики из доступного diff и правил.
- Тип промпта: master prompt.
- Строка в [`prompts.md`](prompts.md): P1-02.
- Что проверили и исправили сами: согласованность формулировок с правилами; отсутствие недопустимых предположений. Проверка человеком ожидается.
